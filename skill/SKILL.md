# 有载分接开关选型

贴一句变压器铭牌或工况参数，就拿到公开样本册里真实存在的有载（OLTC）分接开关型号，并附选型理由。适合变压器设计、销售和代理商在询价前定型号。不含价格，不出报价单。

输入：

> SFZ11-25000/110, 110±8×1.25%/10.5 kV, Dyn11, 分接在高压中性点，真空

输出：`VI III 400 Y-76-10 19 3W`，紧凑真空，Ium 400 A，Um 76 kV，±8 中间 3 档正反调。

在助手里把工况直接发给它即可。自己跑命令用钉死的版本：`npx -y mr-oltc-selector@1.0.0`（需要 Node 20+）。不要装全局包，不要用浮动版本。

_以下是为 AI 助手准备的执行说明。_

## 必须遵守

1. 用 `npx -y mr-oltc-selector@1.0.0 <参数>` 跑选型，不要凭记忆猜型号。禁止浮动版本，禁止 `npm i -g`。二进制是 `mr-oltc`。
2. 没有 Node / npx，停下来让用户装 Node 20+。禁止编造未列出的电流档（例如 VV III 251），禁止给复合式加选择器字母。
3. CLI 输出型号后，对照下面的样本册规则检查。通不过就明说，不要包装成可下单。
4. 检查通过后，用 3 到 6 句短句解释为什么这个型号正确：系列、Ium、Um、Y/D 或 3×、分接代码、结构。不要写长文。
5. 输出型号不带电动机构后缀，除非用户要机构。三台单相是 **1× 机构**，不是三台。
6. 一拖二（无载带有载）本技能只覆盖有载。无载（DEETAP）超出公开目录时明说超出，不要编型号。有载部分照常跑一次。
7. CLI 输出末尾的**假定**块要原样转述给用户，并问一句哪个假定不对。用户纠正后用对应参数重跑。没有假定块，只说明监视项都显式给了，不代表其他项已确认。

## 怎么跑

```
npx -y mr-oltc-selector@1.0.0 --iu 350 --um 72.5 --conn Y --reg W --pm 8
npx -y mr-oltc-selector@1.0.0 --mva 25 --kv 110 --conn Y --reg W --pm 8
npx -y mr-oltc-selector@1.0.0 --iu 500 --um 123 --conn Y --reg W --pm 8 --structure combined
npx -y mr-oltc-selector@1.0.0 --iu 350 --um 76 --conn Y --reg W --pm 8 --oil
```

| 参数 | 含义 |
|------|------|
| `--iu` | Imax（最低分接处的通过电流），不乘安全系数 |
| `--mva` `--kv` | 容量路径，安全系数 `--k`（默认 1.0）只在这里生效 |
| `--um` | 设备 Um（kV），样本册档位 |
| `--conn Y\|D` | 开关应用点：星点 vs 线端。不是变压器 Dyn11 |
| `--reg W\|G\|0` | 正反调 / 粗细调 / 线性调 |
| `--pm` | ± 级数（W/G）。线性调用 `--positions` |
| `--structure` | `auto` / `combined` / `compound` |
| `--ust` | 级电压（V） |
| `--mount` | `in-tank` 箱内（默认）/ `on-tank` 箱顶 / `dry` 干式 |
| `--oil` / `--vacuum` | 灭弧介质。有载默认真空 |
| `--phases` | `I` / `II` / `III`，默认 III |

`--json` 同样没有价格。`--iu` 永远不要再乘 `--k`。

## 读取变压器数据

- `25 MVA 110±8×1.25%/10.5 kV` → `--mva 25 --kv 110 --pm 8 --step-pct 1.25 --reg W`
- `--kv` 是分接侧额定电压。Dyn11 不是 `--conn`。
- Um：`--mva --kv` 时 CLI 会推。110 Y → 72.5（VV/VI 覆盖到 76）。110 D → 123。不要把 110 Y 做成 123。
- 缺电流或电压：先问，不要跑。缺档数、星点/线端、介质、安装：可以跑，假定块会标出来。

## 样本册检查（CLI 之后）

详见 `references/brochure-check.md`。命中任何一条就判不通过：

- **发明电流档**，VV III 只有 250/400/600，没有 251 或 500。500 A 真空三相走 VV 600 或 VM 500 Y。
- **VM / VRS / VRL / OILTAP G 的 III-D**，三相只有星点。线端用 `3x … I-`。VI / VV / OILTAP V 的 III-D 存在。
- **复合式等级字母**，没有 `VV III 250 Y-76/B`。VM / VRS / VRL / G 才带 B/C/D/DE/E。
- **油灭弧**，不会出 VI / VV / VM / VRS / VRL。油型盖不住就说超出目录，不要拿真空顶上。
- **干式 / 箱顶**，本目录没有对应系列，直接超出目录。
- **星点 Um**，110/132 kV 类 Y 工况开关取 72.5（覆盖后 VV/VI 用 76），不是 123。
- **10 19 3W 工作位置数**，19 是机械位置，变压器电压级数是 17。

## 深入 OLTC（解释时用）

- 样本册 Ium 是型号里的电流数字。CLI 输入是 Imax，型号数字是 Ium ≥ 该工况。
- 排名按最低满足：VI → VV → VM → VRS → VRL。油：OILTAP V → G。合法的 III 存在时，一台 III 优于 3× I。
- 选择器默认：≤123 B，170 C，245 D，更高 DE/E。公开例子：`VM III 500 Y-123/B`。
- 分接代码 `P = 2×(±N)+mid`，三个中间位置共用一个电压。

## 选好之后，这样解释

> `VI III 400 Y-76-10 19 3W`：紧凑真空覆盖 76 kV 星点 350 A 工况，升到样本 400 A；VI 的 III-Y 存在，±8 中间 3 档正反调是 10 19 3W，复合式无选择器等级字母，满足要求的最低样本册系列。
> 假定：conn=Y 星点 · reg=W 正反调 · ±8 档 · 真空（默认）· 箱内（默认）· 相数=III（默认）。真空和箱内是我默认的，对吗？

有假定块就照上面这样，型号和短理由之后跟假定，再问一句哪条不对。没有假定块才可以直接停。下单前仍需工程确认。
